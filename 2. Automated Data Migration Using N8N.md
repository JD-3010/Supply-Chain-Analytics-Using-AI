- Go to N8N --> Create a new Workflow
- Click Add 1st Step --> Since we have the data to be monitored or fetched from gmail give gmail as the 1st step.
- On Triggers --> Click **"On Message Received"**
![[Pasted image 20261005093924.png]]

- Configure the Trigger and Sign in the gmail from where the data will flow 
- Set the Monitor Check Duration as per your liking --> Every minute or hour or days etc
![[Pasted image 20261005094122.png]]

- Under Filter --> Choose ==**"Labels & IDs"**== --> Choose "INBOX" since that is where we should check the data 
- Then add a new filter "Search"--> Give the common subject that is used in the mail for the data that is being sent.
- Set the Options --> Tick the Download Attachments box 
- ![[Pasted image 20261005094524.png]]
- Then click --> ==**"Fetch Test Event"**==

- Add a New Node --> Extract Data from file --> Extract data from CSV 
- Give the Input Binary Field as one the files names --> Hit extract in the right side column
- ![[Pasted image 20261005094957.png]]
- You can see the data in Json as we are gonna input this into postgres
- Import your csv files into Supabase and connect the postgres data to N8N
